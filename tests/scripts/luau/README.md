# LuaU Target Test Scripts

This folder contains testing scripts for multiple versions of LuaU.
Each version is sorted by LuaU **Bytecode** versioning.

**Target versions that are supported natively will contain an output of the scripts outputting from CLI testing.**
All supported targets can be found: [here](https://pidova.github.io/Luramas-Docs/docs/supported-targets)
