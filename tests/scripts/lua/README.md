# Lua Target Test Scripts

This folder contains testing scripts for multiple versions of Lua.
Each version is sorted by Lua **Minor** versioning to not pollute targets with the same unchanged targets.

**Target versions that are supported natively will contain an output of the scripts outputting from CLI testing.**
All supported targets can be found: [here](https://pidova.github.io/Luramas-Docs/docs/supported-targets)

## Structure 

* **[lua-5.1-tests/](lua-5.1-tests/)** - Test scripts for Lua version 5.1.xx.
* **[lua-5.2-tests/](lua-5.2-tests/)** - Test scripts for Lua version 5.2.xx.
* **[lua-5.3-tests/](lua-5.3-tests/)** - Test scripts for Lua version 5.3.xx.
* **[lua-5.4-tests/](lua-5.4-tests/)** - Test scripts for Lua version 5.4.xx.
* **[lua-5.5-tests/](lua-5.5-tests/)** - Test scripts for Lua version 5.5.xx.
