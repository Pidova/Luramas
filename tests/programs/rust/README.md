# Rust Target Test Programs

This folder contains testing programs written in Rust. 

* **Organization:** Each test originates from an open-source repository and is stored in a folder named after that repository.
* **Output:** Every test folder contains an `output` directory. This holds the [metadata](https://pidova.github.io/Luramas-Docs/docs/CLI/program-metadata) in `output/metadata` used for parsing builder emissions, as well as its correlating code-generation output in `output/code-generation`.

All supported targets can be found: [here](https://pidova.github.io/Luramas-Docs/docs/supported-targets)
